# ❤️ Heart Attack Prediction

A Machine Learning project that predicts the likelihood of a heart attack based on patient health parameters. The model analyzes medical features and provides predictions that can assist in identifying individuals at potential risk.

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. This project leverages Machine Learning techniques to analyze patient data and predict the risk of a heart attack using various health indicators.

## 🚀 Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Feature selection and engineering
* Machine Learning model training and evaluation
* Heart attack risk prediction
* Performance comparison using evaluation metrics

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Dataset Features

The dataset may include:

* Age
* Gender
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol Level
* Fasting Blood Sugar
* Maximum Heart Rate
* Exercise-Induced Angina
* ST Depression
* Other clinical attributes

## 📈 Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Prediction and Analysis

## 🎯 Objective

To build a predictive model that can classify whether a patient is at risk of a heart attack based on medical and lifestyle factors.

## 📋 Results

The trained model successfully identifies patterns in patient health data and predicts heart attack risk with strong classification performance.
